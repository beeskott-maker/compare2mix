Comment l'importer dans Rekordbox

Réglage à faire une seule fois :

  1. Rekordbox → Préférences → Affichage → Disposition : coche « rekordbox xml ».
  2. Préférences → Avancé → Base de données → « Bibliothèque rekordbox xml » → Parcourir, et choisis le fichier téléchargé. Astuce : choisis plutôt sa copie toujours à jour, qui ne change jamais de place :

À chaque fois :

  1. Barre latérale → rekordbox xml → Listes de lecture (clique sur l'icône d'actualisation si besoin).
  2. Clic droit sur « » → « Importer la liste de lecture ».
  3. La playlist contient ses morceaux actuels + les nouveaux : rien n'est perdu.

Les libellés peuvent varier légèrement selon ta version de Rekordbox.
